## 임베딩과 코사인 유사도 (슬라이드 6~7단계, 54~55)
- 코사인 유사도 = 내적 ÷ (벡터 크기의 곱). **벡터의 방향**이 얼마나 비슷한지(−1~1). 크기는 보지 않는다.
- 임베딩 = 문장을 숫자 목록(벡터)으로. `paraphrase-multilingual-MiniLM-L12-v2`는 384차원. 뜻이 비슷하면 벡터도 비슷하다.
  - "저는 배가 고파요" vs "굶어서 허기가 지네요": **글자가 하나도 겹치지 않아도 0.86**(뜻이 같음).
  - "저는 배가 고파요" vs "저기 배가 지나가네요": **'배' 글자가 같아도 낮음**(0.2~0.4, 뜻이 다름). 문맥이 벡터에 반영된다.
- 우리는 MiniLM 대신 **`BAAI/bge-m3`**(한국어 포함 다국어, 더 좋은 검색 품질)를 쓴다(결정사항.md「기술 스택」). 개념은 같다.

## 검색의 한계와 기준선 — RAG 안전장치의 출발점 (슬라이드 66)
- 후보 문장이 3개뿐일 때 **전혀 관련 없는 질문에도 "그나마 가장 가까운 것"을 무조건 하나 고른다**(예: 학과 이야기에 "저는 배가 고파요" 0.15).
- **유사도는 절대값이 아니라 후보들 중 상대적 순위**다. 관련 있는 질문은 0.85 안팎, 무관한 질문은 0.1~0.2 수준 → **값이 낮으면 "관련 없음"의 신호.**
- 개선: ① **기준선(threshold)**: 최고 점수가 기준 미만이면 "관련된 문장이 없습니다"(최고 점수 표시) ② 후보 문장(문서)을 충분히 늘리기. (수업은 `search(query, docs, threshold=0.5)`)
- 실무 RAG도 같다: 관련 문서가 없으면 **엉뚱한 문서를 근거로 그럴싸한 헛소리(환각)** 를 만든다 → 기준선 + "모르겠다"고 답하기 + 관련 문서 충분히 넣기.
- 이것이 `rag-exercises.md`의 `query_rag_safe`와 우리 `search_health_docs`의 임계값으로 이어진다.

## 파일 읽기와 한글 깨짐 (확장 C~E, 슬라이드 80~89)
- 문서는 코드에 직접 적지 않고 **파일로 관리**하고 `with open(path, encoding='utf-8')`로 읽는다. 쓸 때도 `encoding='utf-8'`을 지정한다.
- **한글이 깨지면 파일이 아니라 읽는 방법(인코딩)이 문제**다. UTF-8이 아닌 파일(예: CP949, 윈도우 메모장/엑셀 저장)을 `utf-8`로 읽으면 `UnicodeDecodeError`(또는 `¿ì¸®` 같은 외계어).
  - 해결: `encoding='cp949'`로 읽기 / `chardet`로 인코딩 자동 감지 / **UTF-8로 변환해 저장하면 근본 해결.**
- 파일이 안 보이면 없는 게 아니라 **다른 폴더를 보고 있는 것**일 수 있다 → `os.getcwd()`와 경로를 비교.

## 오류 읽는 법 (슬라이드 5, 86~87)
- **에러는 마지막 줄부터 읽는다.** "틀리는 것이 실습"이다.
- 터미널 명령은 노트북 셀에 넣으면 `SyntaxError`(노트북에서는 앞에 `!`).
- `ModuleNotFoundError`는 코드가 틀린 게 아니라 **재료가 그 환경에 없는 것**: ① 실행 중인 커널/가상환경이 맞나 ② 정말 미설치면 설치 ③ 설치했는데도 안 되면 다른 환경에 설치했거나 셀을 재실행하지 않은 것. **노트북에서는 `!{sys.executable} -m pip install 패키지`가 가장 확실**하다(지금 쓰는 파이썬에 설치).
- 커널을 재시작하면 변수는 사라지고(`NameError`) 저장된 파일은 남는다. 노트북 화면의 결과는 "마지막으로 실행했을 때"의 것.

## 우리 프로젝트에 적용할 점
- 팀원마다 Python 환경이 다르다(Mac/Windows). `pip install`은 **프로젝트 가상환경(venv)을 활성화한 상태에서**, 안 될 때는 `python -m pip install ...`(지금 쓰는 파이썬)로 설치하면 환경이 헷갈리지 않는다. 이 방법을 README에 적는다.
- 한글 파일(RAG 문서, 시드 데이터, 리포트)은 **모두 UTF-8로 저장**하고, 읽고 쓸 때 `encoding='utf-8'`을 명시한다. 특히 **Windows(권현진)** 에서 `open()`의 기본 인코딩이 cp949라 한글이 깨질 수 있다.
- 임계값 실험: 관련 질문(0.8대)과 무관 질문(0.1~0.2대)의 점수를 직접 찍어 보고 기준선을 정하는 것이 수업의 방식이다.
