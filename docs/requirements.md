# 기말 팀프로젝트 요구사항 체크리스트

- 출처: `docs/lectures/13_기말팀프로젝트_안내.pdf` (12쪽). 원문은 PDF를 직접 확인한다.
- 성적 반영 40%, 2명 팀, 개발 3주, 15주차(12/10) 발표 10분 + 실시간 시연
- 필수 요건을 빠뜨리면 해당 평가 항목이 **'미흡'** 으로 처리된다.

> ⚠ 로컬 LLM 요건: 안내서는 "GPU 서버에서 Ollama 모델(EXAONE·Qwen) 실행, 외부 API는 선택"이라고 쓴다.
> 우리는 Gemini API(결정사항.md 3장)를 쓰기로 했으므로 이 항목이 '미흡'이 될 수 있다.
> 교수님 확인 필요 → `docs/planning/결정사항.md`「미결 사항」.

## 1. 필수 요소 5가지

| 항목 | 기준 | 확인 자료 | 우리 프로젝트 | 상태 |
|---|---|---|---|---|
| 사용자와 하루 시나리오 | 사용자 1명의 아침·낮·저녁, 에이전트가 개입할 순간 표시 | 보고서 1쪽 | `시나리오.md` 5장 압축본 | [ ] |
| 수업 기술 2개 이상 | RAG·도구 호출·LangGraph·CrewAI·MCP 중 서로 다른 2개 이상 | 코드·시연 | 도구 호출, RAG, MCP, LangGraph (4개) | [ ] |
| GPU 서버의 로컬 LLM | 내 GPU 자리에서 Ollama 모델(EXAONE·Qwen) 실행, 외부 API는 선택 | 실행 화면 캡처 | ⚠ Gemini API 사용 중 (위 안내 참고) | [ ] |
| Gradio 웹 데모 | 브라우저에서 직접 조작하는 채팅창 또는 버튼 | 발표일 실시간 시연 | `app.py` | [ ] |
| 보안·윤리·비용 | 개인정보 미수집, 최악의 오작동과 방지책, 응급·의료·법률은 정보 안내로 한정 | 보고서 1쪽 | 기획서 16장 | [ ] |

- 기술 인정 기준: ReAct와 펑션 콜링은 **도구 호출 1개**로 센다.
- 데이터: 공공데이터·학교 공지·가상 데이터만 사용. 실제 개인정보 수집·저장 금지.

## 2. 제출물

- [ ] **GitHub 저장소**: 에이전트·도구 코드 + RAG 데이터. README에 **실행 방법**과 **사용 기술(2개 이상)** 명시
- [ ] **보고서 6~8쪽 (PPT 형태)**: 사용자와 문제 / 기술 선택 이유 / 구현 / 테스트와 개선 / 보안·윤리·비용
- [ ] **AI 활용 보고서 2쪽 (10쪽 양식)**: 핵심 장면 **5개 이상**. 칸 4개 = 어디에 썼나 / 프롬프트 중점 / 기대한 결과 / 실제 결과와 조치
  - 프롬프트 전문이 아니라 판단의 기록. **실패 후 수정한 사례가 더 높은 점수** → `docs/ai-usage-log.md`
- [ ] **발표 10분 + 실시간 시연 + 3분 시연 영상(필수, 서버 장애 대비)**
- [ ] **개인 기여 기술서 (1인 1쪽, 본인 작업 커밋 링크 포함)** + 동료평가. 협업·개인 기여는 개인별로 반영
- [ ] 제출 전 **API 키·비밀번호·웹훅 URL이 코드나 커밋에 없는지** 확인

## 3. 평가 항목과 배점 (100점)

| 평가 항목 | 배점 |
|---|---|
| 문제 정의·사회적 가치 | 15 |
| 기술 구현·설계 타당성 | 30 |
| 완성도·실시간 시연 | 20 |
| 보안·윤리·비용 | 10 |
| 발표·보고서 (AI 활용 보고서 포함) | 10 |
| 협업·개인 기여 | 15 |

- 가점: "최대 5점"과 "기술 3개 이상 구현 시 1개 추가마다 +10점"이 한 칸에 같이 적혀 있어 해석이 갈린다 → 교수님 확인 (결정사항.md「미결 사항」)

## 4. 감점 조건

- [ ] 필수 요건 누락 → 해당 평가 항목 '미흡'
- [ ] 발표에서 **코드를 명확하게 설명하지 못함** → 완성도·기술구현 점수 감점 (코드를 단순하게, "왜 이렇게 짰는지" 말할 수 있게)
- [ ] **AI 활용 보고서 미제출·허위 작성** → 발표·보고서 항목(10점) 0점
- [ ] 실제 개인정보 수집·저장 → 금지 규정 위반

## 6. 테스트 방식 (안내서 6쪽)

- 정상 1 / 모호한 요청 1 / 근거 없음·검색 실패 1, 총 3종으로 시험한다.
- 최종 답변만 보지 말고 **실제로 호출된 도구와 인자**를 함께 확인하고 기록한다 → `docs/test-log.md`
