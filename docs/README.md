## 강의 자료: 요약 md가 기준, PDF는 선택

팀이 함께 보는 기준은 **`docs/reference/`의 요약 md(커밋됨)** 다. PDF 원본(`docs/lectures/`)은 저작권·용량 때문에 커밋하지 않고, 정확한 원문이 필요할 때만 각자 로컬에서 연다. 요약에는 출처 PDF와 쪽·단계 번호가 적혀 있어 원본을 쉽게 찾을 수 있다. Claude도 요약을 먼저 읽고, 부족할 때만 PDF를 연다.

### 새 강의 자료(예: LangGraph, MCP)가 생기면
1. 필요한 부분을 읽고 `docs/reference/<주제>.md`(예: `langgraph.md`, `mcp.md`)로 요약한다.
   - 맨 위에 **출처 PDF 이름과 쪽·단계 번호**를 적는다.
   - 코드는 핵심 부분만 짧게, 마지막에 "우리 프로젝트에 적용할 점"을 쓴다. 원문을 길게 옮기지 않는다(저작권).
2. 위 표와 `CLAUDE.md`의 "무엇을 언제 읽나" 표에 한 줄을 추가한다.
3. **요약 md를 커밋**한다. PDF 자체는 커밋하지 않으므로, 원본이 필요하면 각자 `docs/lectures/`에 넣는다.
4. 시험·과제의 **문제·정답 원문은 요약에 옮기지 않는다**(개념만).

## 문서 쓰는 규칙

- 한국어로 쓴다. 가상 데이터만 쓰고 실명·연락처, API 키, 웹훅 URL은 쓰지 않는다.
- 결정이 바뀌면 `결정사항.md`를 고친다. 다른 문서와 다르면 결정사항.md가 맞다.
