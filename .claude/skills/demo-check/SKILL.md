# 발표 전 점검

항목별로 확인하고 **통과 / 실패 / 확인 필요** 표로 보고한다. 못 확인한 것은 지어내지 않는다.
**비밀값(.env의 키, 웹훅 URL)은 존재 여부만 확인하고 값은 절대 출력하지 않는다.**

## 1. 환경
- [ ] `.env` 존재, `GOOGLE_API_KEY` · `LLM_MODEL` · `DISCORD_WEBHOOK_PATIENT` · `DISCORD_WEBHOOK_GUARDIAN` 키가 **비어 있지 않은지만** 확인 (`.env.example`과 키 목록 대조)
- [ ] `pip install -r requirements.txt` 완료, `python`(Mac은 `python3`)으로 `import` 오류 없음
- [ ] 한글 폰트 `assets/fonts/NanumGothic.ttf` 존재 (리포트 PDF)

## 2. 데이터·인덱스
- [ ] `rag/index/` 에 FAISS 파일 존재, 인덱스 벡터 수 > 0, 검색 1회로 점수·출처·쪽수 표시 확인
- [ ] `rag/docs/` 에 가상 처방 5종 허가정보 + 질병관리청 자료
- [ ] 가상 데이터 시드 완료: DB에 2주치 혈압(평균 약 132/84) · 혈당 · 복약 · 워치 이벤트. 시연 직전 시드를 **초기 상태로 되돌리는 방법** 확인 (같은 날 `DOSE_LOG`가 이미 차 있으면 시연이 깨진다)

## 3. 알림
- [ ] 디스코드 웹훅 테스트: **사용자에게 허락을 받은 뒤** 테스트 메시지 1회 발송("테스트 알림입니다"만. 수치·약 이름 금지). `#복약알림`, `#보호자알림` 둘 다
- [ ] 디스코드 실패 시 Gradio 토스트가 뜨고 `notification_log`에 실패가 기록되는지 (인터넷 끄고 1회)
- [ ] 네트워크 없을 때 캘린더가 `.ics`로 대체되는지

## 4. 시연 순서 리허설 (시나리오.md 7장)
가상 시계: 07:10 → 07:30 → 08:00 → 12:30 → 13:00 → 14:00 → 15:20 → 19:00 → 19:30 → 20:00 → 21:00

| 실시간 시연 (4~5분) | 3분 영상에 추가 |
|---|---|
| ⓪ 캘린더 등록(승인) | ① 재측정 |
| ③ 아침 약 알림 + 디스코드 | ② 용량 질문 거절 |
| ④ 자몽주스 RAG | ⑥ 혈당 |
| ⑤ 중복 체크 경고 | ⑦ 워치 이벤트 |
| ⑧ 무응답 → 보호자 알림 | 6장 위험 수치 분기 |
| ⑨ 리포트 PDF | |

- [ ] 위 순서대로 가상 시계를 넘기며 각 장면이 동작하는지 (한 번 끝까지)
- [ ] 리포트 PDF가 열리고 "가상 데이터" 표기, 한글이 깨지지 않음

## 5. 준비물 (사람이 확인)
- [ ] **휴대폰 핫스팟** 준비(인터넷 필수: Gemini API, 디스코드). 연결 테스트
- [ ] 노트북 충전기 연결, 화면 캡처 준비, 3분 시연 영상 파일 백업
- [ ] 시작 전에 질문 1개를 보내 모델 응답 지연(첫 호출)을 미리 털어 낸다
- [ ] 제출 전: API 키·웹훅 URL이 코드·커밋에 없는지 (`git log -p` 검색)
- [ ] 안내서 요건: 로컬 LLM(Ollama) 관련 교수님 확인 결과 (`docs/planning/결정사항.md`「미결 사항」)
