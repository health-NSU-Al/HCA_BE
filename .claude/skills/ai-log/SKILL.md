# AI 활용 장면 기록

`docs/ai-usage-log.md`에 장면 1개를 추가한다. 메모: `$ARGUMENTS`

## 우선순위
**실패 후 수정한 장면을 우선한다.** (안내서: 실패 사례가 더 높은 점수 — "원하는 게 안 나와서 이렇게 바꿨다"가 핵심.) 프롬프트 전문이 아니라 판단의 기록이다.

## 절차
1. 이 대화에서 방금 한 장면을 파악한다: 무엇을 요청했고, 무엇이 나왔고, 어떻게 바꿨는지.
2. 항목 중 대화에서 알 수 없는 것은 **지어내지 말고 사용자에게 한 번에 묻는다**. 특히 "기대한 결과"는 사용자의 기대이므로 추측하지 않는다.
3. 작성자: `CLAUDE.local.md`의 이름. 없으면 사용자에게 묻는다. 날짜는 오늘.
4. 아래 형식으로 파일 맨 아래에 추가한다(기존 기록은 지우지 않는다). 각 항목은 1~3문장:

```
### [YYYY-MM-DD] 장면 제목 — 작성자
- **어디에 썼나**: (예: 도구 함수 코드 생성, RAG 시스템 프롬프트, 테스트 설계, 발표 자료)
- **프롬프트의 중점**: (무엇에 중점을 뒀나. 전문 붙여넣기 금지)
- **기대한 결과**:
- **실제 결과**:
- **조치**: (어떻게 고쳤나, 채택/일부 채택/폐기)
```

5. 추가 후 현재 기록 개수와 그중 **실패 후 수정한 장면 개수**를 알려 준다. 5개 미만이면 몇 개 더 필요한지 알려 준다.

## 주의
- 실명·연락처, API 키, 웹훅 URL을 기록하지 않는다.
- 허위 작성은 감점(0점) 사유다. 실제로 있었던 일만 쓴다.
