# RAG 규칙

참고: `docs/reference/rag.md`.

- **공공 자료만** 넣는다: 의약품안전나라 허가정보(가상 처방 5종), 질병관리청 국가건강정보포털. 출처 URL·문서명을 남긴다.
- 인덱스 대상은 `rag/docs/` **안의 문서뿐**이다. `docs/`의 기획·참고·강의 문서를 인덱스에 넣지 않는다.
- 설정은 수업 그대로: `PyPDFLoader` → 500자/겹침 50 → `BAAI/bge-m3`(정규화) → FAISS(`MAX_INNER_PRODUCT`) → k=3. 표지·목차 쪽은 제외를 고려한다.
- **검색 최고 점수가 임계값 미만이면 LLM을 거치지 않고 "확인할 수 없어요"로 답한다.** 문구는 상수. 임계값은 `config.py`(권현진 담당 — 값을 바꾸면 공유)에 두고, bge-m3 + 우리 문서로 직접 측정해서 정한다(수업 예시 0.4는 그대로 쓰지 않는다).
- **답변에 출처 문서명과 쪽수를 표시한다.** 쪽수는 `metadata['page'] + 1`.
- 저장할 때와 열 때 임베딩 모델·`distance_strategy`가 같아야 한다. 인덱스는 `rag/index/`(gitignore)에 두고 `python rag/build_index.py`로 만든다.
- 인터넷 없이도 돌아가도록 문서와 인덱스를 로컬에 둔다.
- RAG는 **정보 안내**만 한다. 복용량 조절·진단 문장은 답하지 않는다(`rules/`·`agent/prompts.py`의 안전 규칙).
